# Contributions

Edit original templates in generate.cjs, rebuild with node pullcrest/generate.cjs, and test with node tests/pullcrest.test.cjs. IDs must remain stable. Keep definitions declarative; new operations require engine handling, legal targeting, AI support, rules documentation and tests. Do not parse printed text as rules.

Contributions must be your own or compatible licensed work. Code is MIT, original database and rules CC0. State your rights and acceptance of those licenses. Art must include provenance; do not import commercial cards, characters, databases, logos or source images. Generated variants must remain clearly distinguished from independently designed cards.

Keep changes scoped to PullCrest and its explicit arcade integration. Preserve existing saves and game modules. Review deterministic replay, invalid-action immutability, card-zone conservation, timing, simultaneous knockouts and finite matches. No external repository, server database, collaboration or multiplayer service is implied by source availability.
